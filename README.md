# wkoutre/tap

Homebrew casks for [betterlink](https://github.com/wkoutre/betterlink), a native macOS link router.

```sh
brew install --cask wkoutre/tap/betterlink
```

Each betterlink release carries a filled-in `betterlink.rb`; it is copied here as `Casks/betterlink.rb`. betterlink updates itself, so `brew upgrade` leaves it alone.
